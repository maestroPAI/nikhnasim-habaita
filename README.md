# נכנסים הביתה — frontend חלופי

Frontend עצמאי שמתחבר ל-Base44 הקיים (App ID `6ac0c4d39306549ee04c755b`) באמצעות ה-SDK הרשמי.

## מה קיים
- RTL + mobile-first
- Dashboard לחיץ
- כל הפריטים + חיפוש וקטגוריות
- מסך תקציב ותשלומים
- פריט בודד עם 5 מדדים נפרדים: הערכת מחיר / הצעת מחיר / מקדמה / שולם עד היום / נותר לתשלום
- עריכת הערכת מחיר, הצעת מחיר, סטטוס, קטגוריה והערות
- הוספת תשלום ועדכון `paid_to_date` ו-`remaining_to_pay`
- login מול Base44

## הפעלה
צריך להגיש את התיקייה דרך HTTP/HTTPS (לא `file://`). לדוגמה עם כל שרת סטטי פשוט.

הקוד מייבא את `@base44/sdk` מ-ESM CDN בזמן ריצה.
